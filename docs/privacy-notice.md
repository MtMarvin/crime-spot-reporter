# Privacy Notice

**Project:** Crime Spot Reporter
**Effective Date:** 2026

## 1. About This Notice

This Privacy Notice explains how information may be handled when using the Crime Spot Reporter application.

Crime Spot Reporter is a software project/prototype developed to demonstrate a structured web-based crime reporting process.

## 2. Information That May Be Submitted

Depending on the report category, the application may allow users to provide information such as:

* Date of an incident
* Time of an incident
* Location of an incident
* Description of an incident
* Information about stolen or damaged property
* Suspect-related descriptions
* Other information relevant to the selected crime category
* Photographs or other evidence files where the application provides an upload option

Users should avoid submitting unnecessary personal information.

## 3. Evidence Files

Where file uploads are enabled, photographs, videos, or other supporting files may be stored by the application as part of the demonstration/reporting workflow.

Users should only upload material that they are legally permitted to submit.

## 4. Local Prototype Storage

During development, submitted reports and uploaded files may be stored locally in the application's `submissions` directory.

This storage is intended for development and demonstration purposes.

The prototype should not be treated as a production-grade secure crime-reporting database.

## 5. Sensitive Information

Users should not submit passwords, banking information, identity-document numbers, medical information, or other unnecessary sensitive information through the prototype.

## 6. GitHub and Public Repositories

Development files intended for GitHub should not contain real user crime reports, real evidence files, private information, passwords, API keys, or other confidential material.

Before publishing the project, demonstration data should be removed.

The application's local `submissions` directory should not be committed to a public repository if it contains real or private information.

## 7. Third-Party Services

If future versions of Crime Spot Reporter use third-party services such as cloud storage, mapping services, authentication providers, analytics platforms, or messaging services, their respective privacy policies and terms should also be reviewed.

## 8. Children's Information

The prototype is not specifically designed to collect information from children.

Users should avoid submitting unnecessary information about minors.

## 9. Security

Reasonable development practices should be followed to protect submitted information.

However, this prototype should not be considered a fully secure production system.

Before deployment for real-world use, additional security measures would be required, including appropriate authentication, secure storage, access controls, encryption, logging, validation, backup procedures, and security testing.

## 10. Changes to This Notice

This Privacy Notice may be updated as the application develops.

The latest version should be kept with the project documentation.
