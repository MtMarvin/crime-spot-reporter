# Crime Spot Reporter

## Report Crime. Protect Your Community.

Crime Spot Reporter is a Flask-based web application prototype designed to provide a structured way for users to record and submit information about crime incidents.

The project was developed as a software development and technology project to demonstrate web development, form handling, file uploads, reference generation, and user-friendly crime-reporting workflows.

## Features

* 11 crime-reporting categories
* Structured crime-reporting forms
* Automatic report reference numbers
* Report submission and local storage
* Supporting evidence upload
* Confirmation after successful submission
* Reference-sharing functionality
* Responsive web interface
* Privacy and project documentation

## Crime Categories

The application currently supports:

1. Theft
2. Housebreaking / Burglary
3. Robbery
4. Assault
5. Sexual Offence
6. Vehicle Crime
7. Fraud / Scam
8. Vandalism
9. Murder
10. Drug / Illegal Activity
11. Other Crime

## How It Works

1. The user opens Crime Spot Reporter.
2. The user selects **Report a Crime**.
3. The user chooses a crime category.
4. The user completes the relevant reporting form.
5. Supporting evidence can be uploaded where available.
6. The application generates a unique reference number.
7. The report is saved by the application.
8. The user receives a confirmation containing the reference number.

## Important Notice

It is not an official South African Police Service system, government reporting platform, or emergency service.

For emergencies or situations requiring immediate assistance, users should contact the appropriate official emergency or law-enforcement services.
